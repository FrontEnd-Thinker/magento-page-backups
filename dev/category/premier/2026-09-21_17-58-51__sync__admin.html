Capture Client Premier at a Glance

NGAV and Behavioral AI

SentinelOne's AI engine identifies threats by behavior, not signatures. It stops ransomware, fileless attacks, and zero-days before they execute, without waiting for daily definition updates or a full scan window.

Endpoint Detection and Response

Full EDR with threat hunting, forensic timeline analysis, and 1-click investigation. See exactly what executed on each endpoint, when it ran, and what it touched. Drill to root cause without leaving the management console.

Rollback and Recovery

If an attack succeeds, Premier restores the endpoint to its last known-clean state automatically. No manual re-imaging, no extended downtime. Rollback is supported on Windows endpoints and preserves user data throughout the process.

SonicWall Ecosystem Integration

Runs alongside SonicWall next-generation firewalls and optionally forwards unknown files to Capture ATP cloud sandbox for additional analysis. No firewall is required, but the integration adds a second inspection layer for organizations that already run SonicWall.

Capture Client Premier FAQ

Capture Client Premier is SonicWall's top-tier endpoint protection product. It combines SentinelOne-powered next-generation antivirus, full endpoint detection and response (EDR), forensic timeline analysis, threat hunting, and the ability to roll back a compromised endpoint to its last known-clean state, all managed from the SonicWall cloud console.

Capture Client Premier captures volume shadow copies before suspicious activity begins. If an attack is confirmed, the platform restores the endpoint to its last known-clean state without manual re-imaging. The process preserves user data and gets the machine back to a working state far faster than a clean OS install. Rollback is supported on Windows endpoints.
