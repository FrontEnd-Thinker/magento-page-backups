TZ270W at a Glance

Performance

2 Gbps firewall inspection, 750 Mbps threat prevention, 1 Gbps IPS throughput, 300 Mbps DPI-SSL. Up to 6,000 new connections per second and 750,000 concurrent SPI connections.

Wireless

Built-in dual-band 802.11ac Wave 2 radio supporting 2.4 GHz and 5 GHz bands. WPA3 encryption, 2x2 MIMO, virtual access point (VAP) segmentation, WIDS/WIPS, and wireless guest services with captive portal.

Wired Interfaces

Eight 1GbE copper ports, two USB 3.0 ports for cellular failover, and one RJ45 console port. Expandable storage up to 256 GB for logging, caching, and firmware backup.

Security Services

TZ270W FAQ

The TZ270W includes a built-in dual-band 802.11ac Wave 2 wireless radio. Everything else, including the firewall throughput, ports, security services, and VPN capacity, is identical to the wired TZ270. If you need integrated Wi-Fi, choose the TZ270W.

The TZ270W uses 802.11ac Wave 2 with 2x2 MIMO, supporting both the 2.4 GHz and 5 GHz bands. It supports WPA, WPA2, and WPA3 encryption, and includes wireless intrusion detection and prevention (WIDS/WIPS).

Yes. The TZ270W supports virtual access point (VAP) segmentation, which lets you create isolated SSIDs for guests, IoT devices, or different user groups. Each VAP can have its own security policies and VLAN assignment.

The TZ270W supports up to 50 site-to-site IPSec VPN tunnels and up to 200 IPSec VPN clients with full licensing. It includes one SSL VPN license (up to 50 SSL VPN users when licensed).

Yes. The TZ270W includes two USB 3.0 ports that accept USB 5G and LTE dongles for cellular WAN failover. This allows the firewall to automatically shift traffic to a cellular connection if your primary ISP link goes down.
