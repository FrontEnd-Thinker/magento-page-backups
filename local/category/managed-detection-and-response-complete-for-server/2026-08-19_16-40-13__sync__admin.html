MDR Complete for Server at a Glance

What you get

A Sophos-run security operations center working your servers 24/7/365, plus full-scale incident response at no extra cost. When a threat is confirmed, Sophos analysts neutralize it end to end with no hourly caps, led by a dedicated Incident Response Lead.

Built on Intercept X

The bundle includes Intercept X Advanced for Server with XDR, running as a single lightweight agent. The same agent and license apply whether the server is on-prem, virtual, or in the cloud, and it covers both Windows Server and Linux.

Complete vs Essentials

Both tiers include 24/7/365 monitoring, threat hunting, and active containment. Complete adds full incident response, a 60 minute response target on 90% of high-severity cases, and a $1M breach protection warranty, so Sophos finishes the response instead of handing it back to you.

Integrations and retention

Beyond Sophos firewall, email, and cloud, MDR pulls telemetry from 350+ third-party integrations across firewall, network, email, cloud, and identity for deeper detection context. Data storage is 90 days by default, with a one year extended option.

Not sure if Complete or Essentials fits?

Both tiers give you a Sophos SOC watching your servers. The real difference is who finishes the response. Compare the editions side by side, or talk to a Sophos-certified expert who can size it for your estate.
