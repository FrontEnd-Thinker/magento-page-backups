FortiWiFi 30G at a Glance

Performance

Firewall throughput 4 Gbps. NGFW throughput 570 Mbps. Threat protection 500 Mbps. IPSec VPN throughput 800 Mbps. SSL inspection throughput 400 Mbps. Up to 600,000 concurrent sessions. Powered by the FortiASIC SoC4 purpose-built SD-WAN and security processor.

Connectivity

4x GE RJ45 ports (3 internal, 1 WAN). Three external detachable antennas on FortiWiFi models. USB 2.0 management port. Console port. Supports active-passive high availability for network resilience. Desktop or wall-mount form factor, fully fanless.

Security and SD-WAN

FortiGuard AI-Powered Security Services cover IPS, antivirus, web filtering, DNS filtering, application control, and anti-botnet protection. Secure SD-WAN with dynamic path selection, application steering, and WAN quality monitoring is built into FortiOS at no added cost.

Management

Runs FortiOS, Fortinet's converged networking and security OS. Managed on-premises via FortiManager, in the cloud via FortiGate Cloud, or as a service via FortiGate-as-a-Service. Zero Touch Provisioning supports large-scale branch rollouts. FortiLink integrates FortiSwitch and FortiAP as logical extensions of the firewall.

Not sure which 30G model is right for you?

The 30G family includes four SKUs. The FortiGate 30G and FortiWiFi 30G are wired and wireless versions at the same performance level. The 31G variants add a 30 GB onboard SSD for local logging and reporting. Step up to the 50G or 70G series for higher throughput and session capacity.
