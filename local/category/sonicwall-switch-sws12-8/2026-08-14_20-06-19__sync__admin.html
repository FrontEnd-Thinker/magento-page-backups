Switch 12-8 at a Glance

Performance

20 Gbps non-blocking switching capacity with an 8K MAC address table and 512KB packet buffer. All 8 copper ports run at 10/100/1000 Mbps with auto-negotiation and MDI/MDIX auto-crossover.

Connectivity

8 x 1G RJ45 copper ports for wired clients plus 2 x 1G SFP uplink slots for fiber connectivity to the core. Supports jumbo frames and 802.3ad link aggregation for uplink redundancy.

Management

Managed through SonicWall firewalls, Wireless Network Manager, or the standalone web GUI. Supports SNMP monitoring, SSH, CLI, SNTP/NTP, syslog, and zero-touch deployment via Capture Security Center.

Power and Form Factor

Fanless desktop design draws only 5.7W maximum. Powered by an included 24W external adapter (12 VDC). Dimensions: 240 x 105 x 27mm, 0.62 kg. MTBF rated at over 1.3 million hours.

Switch 12-8 FAQ

The SonicWall Switch 12-8 (model SWS12-8) is a compact, fanless desktop gigabit switch with 8 x 1G RJ45 copper ports and 2 x 1G SFP uplink ports. It is designed for small business and branch office environments and integrates with SonicWall firewalls and Wireless Network Manager for unified, single-pane-of-glass management. It does not include Power over Ethernet.

No, the Switch 12-8 does not support Power over Ethernet. If you need to power devices like wireless access points, VoIP phones, or IP cameras directly from the switch, consider the Switch 12-8-PoE (802.3af, 55W total) or the Switch 12-10-FPoE (802.3at, 130W total).

The Switch 12-8 can be managed three ways: through a SonicWall next-generation firewall using Network Security Manager, through SonicWall Wireless Network Manager for wireless-centric deployments, or through the switch's own standalone web GUI and CLI. It also supports zero-touch deployment via Capture Security Center, SNMP monitoring, SSH, and syslog.

The Switch 12-8 supports 802.1X port-based authentication, MAC Authentication Bypass (MAB) for devices that cannot perform 802.1X, IP and MAC access control lists, DHCP snooping, port security, port isolation, and storm control. When managed through a SonicWall firewall, it also benefits from IPS, gateway anti-virus, application control, and botnet filtering enforced at the firewall level.

Yes. The Switch 12-8 includes a standalone web GUI and CLI that allow full configuration without a SonicWall firewall. However, firewall-managed mode unlocks centralized VLAN configuration, zero-touch deployment, automated switch discovery, and unified security policy enforcement. For the best management experience, pairing it with a SonicWall firewall is recommended.
