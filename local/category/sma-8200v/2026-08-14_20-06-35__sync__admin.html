SMA 8200v at a Glance

Virtual Performance

Up to 1.58 Gbps SSL VPN throughput with 5,000 concurrent sessions. Runs on a 4-core vCPU allocation with 8GB RAM and a 240GB recommended virtual disk. Performance scales with the resources allocated by the host hypervisor.

Deployment Flexibility

Runs on VMware ESXi and Microsoft Hyper-V on-premises and on KVM-based infrastructure. Deploys natively in AWS and Microsoft Azure for hybrid-cloud environments where physical appliances are not an option. All deployment types run the same SMA OS 12.4 firmware.

Access Security

FIPS 140-2 Level 2 certified. Advanced Endpoint Control (EPC) verifies device posture before granting access, the same as physical SMA appliances. Capture ATP for SMA integrates as a cloud-based subscription to scan files uploaded by remote users.

Scale and Management

CMS can cluster up to 100 SMA 1000 instances, mixing physical 6210 and 7210 appliances with 8200v virtual nodes in the same mesh. CMS shares session state globally and pools licenses dynamically, so regional capacity is never wasted during off-peak hours.
