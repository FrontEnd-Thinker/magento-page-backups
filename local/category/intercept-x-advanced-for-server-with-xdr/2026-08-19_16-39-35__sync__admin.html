Intercept X for Server with XDR at a Glance

Threat Prevention

Deep learning anti-malware, exploit prevention, and active adversary mitigation work together to stop attacks before they run, including threats that slip past traditional tools.

Anti-Ransomware

CryptoGuard detects malicious encryption and rolls affected files back automatically. WipeGuard protects the master boot record from wipe and boot-record attacks.

Server Controls

Server Lockdown allow-lists the applications your server is meant to run, and File Integrity Monitoring flags unexpected changes to critical files.

XDR & Investigation

Correlate detections across endpoint, server, firewall, and email, then hunt for active adversaries and use root cause analysis to see what happened and where it started.

Intercept X for Server FAQ

Per server. You buy one license for each server you want to protect. That is the key difference from the workstation product, Intercept X for Endpoint, which is licensed per user. If you are covering servers, count servers, not people.

One server license per virtual machine. Each Windows or Linux VM you protect counts as a server, whether it runs in your data center, in AWS, or in Azure. So 24 Azure VMs need 24 licenses. The tier you see (1 to 9 servers, 10 to 24, and up) just sets the per-license price. You buy a quantity equal to your server count, not one license that covers a range.

You keep every protection feature, including deep learning anti-malware, exploit prevention, CryptoGuard, and Server Lockdown. XDR adds the investigation layer on top. It pulls detection data from your endpoints, servers, firewall, and email into one place so you can hunt for active threats, answer the hard questions after an incident, and trace an attack back to its root cause across products, not just on a single server.

XDR is the toolset your own team uses to detect, investigate, and respond. MDR, Managed Detection and Response, is a service where the Sophos team does that hunting and response for you, around the clock. If you have the staff and want the controls, XDR fits. If you would rather hand off 24/7 monitoring, ask us about adding MDR. We can quote either.
