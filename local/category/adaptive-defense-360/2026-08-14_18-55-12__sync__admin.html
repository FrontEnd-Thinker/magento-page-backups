Adaptive Defense 360 FAQ

Traditional antivirus relies on signature databases to catch known threats. Panda Adaptive Defense 360 goes further by combining signature-based detection with behavioral EDR, exploit prevention, and the Zero-Trust Application Service, which classifies 100% of running processes using machine learning and cloud intelligence. This means AD360 catches fileless attacks, living-off-the-land techniques, and zero-day threats that bypass conventional antivirus entirely.

No. Adaptive Defense 360 is fully cloud-managed through the Aether platform. There is no on-premise management server to install or maintain. Administrators access the console through any web browser, and the lightweight endpoint agent communicates directly with Panda's cloud infrastructure. This makes deployment fast and reduces overhead for IT teams of any size.

Adaptive Defense 360 supports Windows (Windows 7 SP1 and later, including Windows Server 2008 R2 and later), macOS (10.13 High Sierra and later), Linux (major distributions including RHEL, CentOS, Ubuntu, Debian, and SUSE), and Android. iOS coverage is available through the Adaptive Defense 360 Mobile add-on.

Every application and process that attempts to run on a protected endpoint is sent to Panda's cloud intelligence for classification. The service uses machine learning models trained on billions of samples to determine whether the process is safe, malicious, or unknown. Unknown processes are blocked and monitored in a restricted mode until they are fully classified, ensuring no unverified code executes freely in your environment.
