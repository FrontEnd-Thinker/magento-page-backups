Cloud Secure Edge at a Glance

Full SSE Stack in One Subscription

CSE covers ZTNA for private application access, Secure Web Gateway (SWG) for internet traffic inspection, Cloud Access Security Broker (CASB) for SaaS application visibility and control, and DNS Security for threat blocking at the resolution layer. All four services run from the same cloud platform under a single license and are managed from one dashboard. There is no second console and no separate appliance to size or rack.

Firewall Connector for Gen 7 and Gen 8

Existing SonicWall Gen 7 and Gen 8 firewall customers activate the CSE Connector from within SonicOS 7.1.2 or later in a few clicks. The connector gives ZTNA access to private applications hosted behind the firewall without reconfiguring the firewall or opening inbound ports. Shared threat intelligence flows between the firewall estate and the CSE cloud, so a threat seen at the perimeter is known to the access layer immediately.

Basic vs. Advanced

The Basic tier delivers essential ZTNA and DNS Security for organizations that need secure remote access without full internet access inspection. The Advanced tier adds full SWG, SSH and RDP session recording, and comprehensive CASB functionality for SaaS application control. Both tiers include multi-tenant management, Zero Touch and MDM deployment, and Single Sign-On. Advanced is the right choice for organizations replacing a full SSL VPN and proxy stack in a single motion.

Built for MSPs

CSE is licensed and billed through MySonicWall alongside existing firewall and security subscriptions. Monthly billing is available for MSPs that charge customers on a consumption model. The multi-tenant management portal lets MSP technicians manage all customer tenants from a single interface. Guided migration tooling and a coexistence mode let you run CSE alongside an existing SSL VPN deployment while you complete the transition, with no disruption to users in the interim.

Still running SonicWall SSL VPN or Global VPN Client?

CSE is the purpose-built replacement for both. Customers report a full SSL VPN migration in under two weeks with guided migration tooling. Our engineers can walk you through the coexistence period and help you size the right CSE tier for your user count and application mix.
