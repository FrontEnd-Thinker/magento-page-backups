Deployment

Hypervisors: VMware ESXi, Microsoft Hyper-V, KVM, and Citrix.
Cloud (BYOL): Amazon Web Services and Microsoft Azure.
Bare metal: install as a software appliance on your own Intel-based server.

Licensing

A perpetual base license covers core firewall, IPSec and SSL VPN, wireless, and Sophos Central management. Licensing is counted by vCPU cores, not per user. Since March 2025 there is no RAM cap on virtual, software, and cloud BYOL licenses, so this Unlimited Cores tier uses all the RAM you assign.

Protection

Standard Protection: Network Protection (IPS and ATP), Web Protection, and Enhanced Support.
Xstream Protection: everything in Standard plus Zero-Day Protection sandboxing, TLS 1.3 inspection, DNS Protection, and Central Orchestration for SD-WAN.

Performance & Sizing

Throughput on a virtual appliance depends on the host you give it, so we don't quote fixed numbers. Assign enough vCPU, RAM, and NIC bandwidth for your traffic, then scale up later without swapping hardware. Need a hand sizing it? Talk to a Sophos-certified rep.
