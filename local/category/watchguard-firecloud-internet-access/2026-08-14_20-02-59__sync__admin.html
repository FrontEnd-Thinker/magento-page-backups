FireCloud at a Glance

No Hardware Required

FireCloud delivers full NGFW inspection from the cloud. Branches and remote users connect without deploying a physical appliance, reducing hardware costs and complexity.

Full Security Stack

Intrusion Prevention, Application Control, URL Filtering, antivirus, and botnet detection are all included. FireCloud does not trade inspection depth for delivery model.

Unified Management

FireCloud policies are managed from WatchGuard Cloud alongside physical Firebox appliances, giving administrators a single policy framework for every location.

Scalable by Design

FireCloud scales automatically with traffic volume. Organizations can add users or locations without pre-provisioning additional capacity.

FireCloud FAQ

WatchGuard FireCloud is a cloud-delivered firewall-as-a-service (FWaaS) solution. It provides full next-generation firewall inspection, including IPS, application control, URL filtering, and antivirus, delivered from WatchGuard's cloud infrastructure. It is designed for distributed organizations, cloud workloads, and remote branch connectivity where deploying a physical appliance is not practical or preferred.
No. FireCloud delivers firewall services entirely from WatchGuard's cloud infrastructure. Branches and remote users connect to the nearest WatchGuard cloud enforcement point without any on-site hardware. If you already have physical Firebox appliances at some locations, those can coexist and be managed from the same WatchGuard Cloud console.
FireCloud includes Intrusion Prevention (IPS), Application Control, URL Filtering, antivirus, and botnet detection. These are the same security service categories available on WatchGuard's Firebox hardware line, delivered without a physical appliance at each site.
FireCloud supports IPsec VPN, SD-WAN, and branch-to-cloud connectivity. Traffic from branch offices and remote users is routed to the nearest WatchGuard cloud enforcement point for inspection. This keeps latency low while applying consistent security policies across every connected location.
FireCloud is available as a subscription, licensed per user or per bandwidth tier depending on your deployment model. Licenses are managed from WatchGuard Cloud alongside any Firebox hardware subscriptions you hold.
