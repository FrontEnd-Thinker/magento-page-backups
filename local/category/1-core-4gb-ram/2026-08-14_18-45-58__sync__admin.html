Virtual Firewall at a Glance

Full Feature Parity

Every Sophos Firewall feature is available on the virtual appliance, exactly as it is on XGS hardware. That means the Xstream DPI engine, IPS, application control, TLS inspection, web filtering, and unlimited remote access and site-to-site VPN. Nothing is locked behind a bigger form factor.

Licensing

Licensed by CPU core count, not by a hardware model. As of the 2025 Sophos change, virtual, software, and cloud licenses no longer cap RAM, so this 1 core license runs with all the memory you allocate. Pair the base license with a protection bundle and a support term.

Where It Runs

Deploy on VMware, Microsoft Hyper-V, KVM, or Citrix, in Microsoft Azure or AWS with pay-as-you-go or bring-your-own-license pricing, or on Nutanix AHV. You can also install the same software on your own Intel x86 hardware.

Management

Managed like every Sophos Firewall, locally or through Sophos Central. One console handles policy, reporting, and Security Heartbeat across your hardware and virtual firewalls, so a virtual deployment slots into an existing Sophos estate without a new toolset.

Not sure how many cores you need?

The Sophos Virtual Firewall comes in 1, 2, 4, 6, and 8 core tiers plus an unlimited option. Line them up and match the core count to your throughput and user load.
