VM32 at a Glance

Virtual Hardware Requirements

32 vCPU cores licensed maximum — the highest tier in the FortiMail VM lineup.
Memory: 4 GB minimum, up to 128 GB recommended for peak load.
Storage: 250 GB minimum (for initial OVF deployment, can shrink to 50 GB after), up to 24 TB maximum.
Requires 1–6 virtual NICs.

Capacity

Supports up to 2,000 protected email domains and 1,500 / 7,500 recipient-based policies (per domain / per system).
Server Mode supports up to 3,000 local mailboxes.
Antispam, antivirus, authentication, and content profiles: 50 / 600 (per domain / per system).

Supported Platforms

Runs on VMware ESX/ESXi 6.0+, Microsoft Hyper-V Server (2012/2016/2019), KVM (qemu 2.12.1+), and Citrix XenServer.
Also deployable on AWS, Microsoft Azure, Google Cloud Platform, Oracle Cloud Infrastructure, and Nutanix AHV.

Deployment & Licensing

Supports Gateway, Transparent, and Server mode deployments.
Includes Data Loss Prevention and centralized quarantine by default.
Optional Microsoft 365 / Google Workspace API integration add-on.
Licensed via 24x7 FortiCare + FortiGuard Base or Enterprise ATP bundle contracts.

VM32 FAQ

FortiMail VM32 is licensed for a maximum of 32 virtual CPU cores — the highest vCPU tier Fortinet offers for FortiMail-VM, per Fortinet's official data sheet. It's recommended for the largest enterprise deployments.

Fortinet specifies a minimum of 4 GB of RAM up to a maximum of 128 GB (the same ceiling as VM16), and a minimum of 250 GB of storage up to a maximum of 24 TB — double VM16's storage ceiling — depending on mailbox count and retention needs.

VM32 supports VMware ESX/ESXi 6.0 and later, Microsoft Hyper-V Server, Citrix XenServer, and KVM on-premises, plus AWS, Microsoft Azure, Google Cloud Platform, Oracle Cloud Infrastructure, and Nutanix AHV in the cloud — the same platform matrix as the rest of the FortiMail VM lineup.

Choose VM32 when your organization's peak inbound/outbound mail volume, protected domain count (up to 2,000 vs. 1,500), or storage/retention needs exceed what VM16 can sustain. VM32 roughly doubles message throughput and maximum storage over VM16.

Data Loss Prevention and centralized quarantine are included at the VM32 tier. Optional add-ons such as content disarm and reconstruction, sandboxing, impersonation analysis, and Microsoft 365 / Google Workspace API scanning are available through Fortinet's Enterprise ATP bundle.
