Panda Advanced Reporting Tool. One year of endpoint intelligence, always at your fingertips.

Panda Advanced Reporting Tool (ART) is an Elastic-powered SIEM add-on built directly into the Aether platform. It captures and retains up to one year of endpoint telemetry from every Adaptive Defense or Adaptive Defense 360 protected device, making that data searchable in real time through pre-built threat hunting dashboards and a free-form query interface. Security teams use ART to investigate past incidents, hunt for indicators of attack, satisfy compliance audit requirements, and correlate endpoint activity across the full device fleet without managing a separate SIEM infrastructure.

Advanced Reporting Tool at a Glance

Historical Telemetry Querying

Query up to one year of endpoint events including process executions, network connections, file system changes, and user logon activity. Search across your entire device fleet in seconds using the Elastic-powered query engine embedded directly in Aether.

MITRE ATT&CK Dashboards

Pre-built dashboards map detected endpoint activity to MITRE ATT&CK tactics and techniques. Security analysts can immediately see which attack phases are represented in their telemetry without building custom visualizations from scratch.

Compliance and Audit Evidence

Generate detailed reports on security events, blocked threats, user activity, and device posture. One year of retained data provides the historical evidence required for PCI DSS, HIPAA, ISO 27001, and other compliance frameworks that mandate activity logging.

External SIEM Integration

In addition to the built-in ART interface, endpoint events can be forwarded to Splunk, Microsoft Sentinel, IBM QRadar, or any syslog-compatible SIEM. ART and external SIEM integration are not mutually exclusive and can run simultaneously.

Advanced Reporting Tool FAQ

Yes. The Advanced Reporting Tool is an add-on that extends either Adaptive Defense or Adaptive Defense 360. It requires an active subscription to one of those endpoint protection products because it draws its data from the telemetry those agents collect. ART is not a standalone SIEM and cannot ingest data from non-Panda sources.

ART captures a comprehensive set of endpoint events including process creation and execution, network connection attempts, file system operations, registry changes, user logon and logoff events, detected threats and blocked activity, and device inventory changes. All events are timestamped and attributed to specific devices and users, giving analysts full context for investigation and reporting.

Endpoint telemetry collected by ART is stored in Panda Security's cloud infrastructure using Elastic. Data is encrypted in transit and at rest. Access is controlled by Aether role-based permissions, so only administrators with the appropriate access level can query or export the retained telemetry. Panda publishes its data handling practices in its security and privacy documentation.
