VM04 FAQ

FortiADC VM04 is licensed for up to 4 vCPU cores. Fortinet doesn't publish a fixed RAM cap for FortiADC-VM — memory support is unlimited, so you size RAM to your hypervisor, VDOM count, and expected load-balancing throughput; budget more memory here than on VM01/VM02 if you're running multiple virtual services or heavier SSL offload.
