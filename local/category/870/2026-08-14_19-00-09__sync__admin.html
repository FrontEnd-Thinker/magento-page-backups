NSv 870 at a Glance

Performance

38 Gbps firewall inspection throughput and 6.5 Gbps of active threat prevention, optimized for high-throughput data center use cases where virtual machine density and east-west traffic volumes require enterprise-class capacity.

Platform Support

Supported on VMware ESXi, Microsoft Hyper-V, and KVM. Available in AWS Marketplace, Azure Marketplace, and Google Cloud Marketplace. Supports DPDK on compatible hypervisors for optimized packet forwarding.

Security Services

Complete AGSS support with Capture ATP, RTDMI, TLS 1.3 inspection, IPS, Gateway Anti-Virus, and Application Control, providing the same depth of inspection as NSsp-class hardware in a virtual form factor.

Management

SonicOS 7.0 with NSM centralized management and REST API. NSv 870 instances can be templated and provisioned automatically as part of cloud-native CI/CD pipelines.
