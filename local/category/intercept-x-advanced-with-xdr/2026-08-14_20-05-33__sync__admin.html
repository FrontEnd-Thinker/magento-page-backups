Intercept X Advanced with XDR at a Glance

Prevention First

Deep learning malware detection stops known and unknown threats without leaning on signatures. Exploit prevention blocks the techniques attackers reuse across zero-days, and CryptoGuard shuts down ransomware and rolls encrypted files back to their last safe state.

Detection and Response

EDR lets your team hunt active adversaries and run guided investigations. XDR widens that view beyond the device, pulling in signal from your endpoints, servers, firewall, email, and cloud so you can trace an attack end to end. Root cause analysis shows how it started.

Platform Support

Protects Windows, macOS, and Linux desktops and laptops, plus Windows Server. Server workloads are covered by a separate product, Intercept X Advanced for Server with XDR, so you license desktops and servers on the terms that fit each.

Licensing and Deployment

Licensed per user in volume tiers (1-9, 10-24, 25-49, 50-99, and up) on 1, 2, or 3 year terms. New buyers and teams switching from another vendor (Competitive Upgrade) both have options. Runs from Sophos Central, so there are no on-prem servers to deploy.
