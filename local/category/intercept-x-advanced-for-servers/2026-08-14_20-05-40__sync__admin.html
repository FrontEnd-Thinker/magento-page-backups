Intercept X for Server at a Glance

Stops Threats Before They Run

Deep learning anti-malware flags known and never-before-seen threats without waiting on signatures. Exploit prevention blocks the techniques attackers reuse against unpatched software, and active adversary mitigation keeps them from gaining a foothold.

Anti-Ransomware Built In

CryptoGuard detects unauthorized file encryption, whether it starts on the server or reaches it from a compromised endpoint, and rolls affected files back to a safe state. WipeGuard protects the boot record from the same class of attack.

Server Lockdown

One-click application whitelisting freezes a clean server in a known-good state so nothing unapproved can run. File integrity monitoring flags changes to critical files, which matters for both security and compliance.

Built for Cloud & Hybrid

One agent and one policy cover physical, virtual, and cloud servers alike. AWS and Azure workload discovery keeps your inventory current, and root cause analysis shows exactly how an incident unfolded. Add XDR to extend threat hunting across your whole estate.

Intercept X for Server FAQ

It is a full replacement, not an add-on. Intercept X Advanced for Server combines modern techniques like deep learning anti-malware, exploit prevention, and CryptoGuard anti-ransomware with foundational ones like signature-based detection, behavior analysis, application control, and web filtering. Once it is deployed you can remove your existing server antivirus. Note that firewall and email protection are sold separately, so most teams pair this with a Sophos firewall.

You license it per server, once for each server you want to protect, on a 1, 2, or 3-year subscription. Pricing runs in count-based bands (1 to 9, 10 to 24, 25 to 49, and up), and each band carries a minimum quantity. If you are protecting three servers, you buy three licenses in the 1 to 9 band. Not sure which band or term is most cost-effective for your environment? Request a quote and a Sophos-certified rep will size it with you.

Server workloads are different from user endpoints, so the protection is tuned for them and licensed separately. The server edition adds features desktops do not get, like Server Lockdown application whitelisting, file integrity monitoring, and AWS and Azure workload discovery, and it is optimized to run with minimal resource use on production servers. Virtual machines and cloud instances count as servers here, so a Windows or Linux VM needs a server license, not a user one.

All three share the same core prevention. Intercept X Advanced for Server gives you the full protection stack. Adding XDR (extended detection and response) layers on cross-product threat hunting and investigation across servers, endpoints, firewall, and email, and it is required for Linux runtime detections. The MDR edition adds Sophos Managed Detection and Response, a team that hunts and responds around the clock on your behalf, and it includes the XDR tooling. Pick the standard edition for prevention, XDR if your team runs its own investigations, and MDR if you want Sophos to run the security operations.

It protects Windows Server, common Linux distributions, and UNIX, whether the server is physical, virtual, on-premises, or running in AWS or Azure. The license policy and the agent are the same across all of them, so a mixed estate deploys and manages the same way from Sophos Central. Linux offers two deployment options, a full protection agent and a lighter anti-virus agent, and the two cannot run together on the same host.
