Fortinet FortiADC 1000F. High-Performance Application Delivery Controller

The FortiADC 1000F is a 1U application delivery controller built for data center load balancing, SSL/TLS offload, and application acceleration at scale. It combines ASIC-based hardware SSL acceleration with advanced Layer 4/7 load balancing, Global Server Load Balancing (GSLB), and a built-in Web Application Firewall to keep demanding applications fast, available, and secure. With dual redundant power and high-density 10GE connectivity, the 1000F is a solid fit for mid-size data centers consolidating server load balancing and SSL offload onto a single platform.

FortiADC 1000F FAQ

The FortiADC 1000F delivers up to 20 Gbps of Layer 4 throughput and 15 Gbps of Layer 7 throughput, with support for up to 18 million concurrent connections and 425,000 new connections per second.

The 1000F uses ASIC-based hardware SSL acceleration to deliver up to 20,000 SSL transactions per second (2K RSA keys) and 7.5 Gbps of SSL bulk encryption throughput, offloading CPU-intensive TLS processing from your backend servers.

Yes. The 1000F supports VRRP-based Active-Active and Active-Passive HA failover, along with included Global Server Load Balancing (GSLB) for multi-data-center resiliency and disaster recovery.

The 1000F ships with 4x 10GE SFP+ ports, 8x GE SFP ports, and 8x GE RJ45 ports, plus a dedicated GE RJ45 management port, giving you a flexible mix of 1GbE and 10GbE connectivity for server-facing and client-facing links.

The 1000F is built for mid-size to large data centers and hybrid IT environments that need dedicated hardware-based load balancing and SSL offload, without the interface density or throughput demands of a large multi-tenant hosting environment.
