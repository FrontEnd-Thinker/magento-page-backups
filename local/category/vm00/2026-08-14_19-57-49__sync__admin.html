Fortinet VM00. Free 15-Day Evaluation License — 1 vCPU

FortiMail VM00 is Fortinet's built-in 15-day evaluation license for the FortiMail virtual appliance. It activates automatically the first time you power on FortiMail VM, running the full feature set on a single vCPU so you can test gateway, transparent, or server-mode email security before committing to a production license. Because it's a trial rather than a purchased tier, live FortiGuard antispam and antivirus signature updates require a valid service contract, and only low-strength encryption is available for the admin GUI. When you're ready for production use, apply a VM01 or higher license to the same instance — no reinstall required.
